# 📝 Mission Reflection

Writing a `docker-compose.yml` file made me realize how much easier it is to manage an application when everything is organized in one configuration file. Instead of manually typing several Docker commands for each container, I can define the services, environment variables, and other settings in YAML and start them together using `docker compose up -d`. However, I also learned that small mistakes can cause problems. For example, using a Tab instead of spaces or having incorrect indentation can make the YAML file invalid, preventing Docker Compose from reading the configuration properly. This taught me to be more careful when writing code because even a small formatting error can affect the entire deployment.

I also understood why environment variables, such as `MYSQL_PASSWORD`, are used in the Compose file. They allow us to configure important settings without directly placing every value in the application configuration. This makes the setup more flexible and easier to maintain. However, I learned that passwords should still be handled carefully because environment variables are not automatically secure. Sensitive information should not be shared publicly or committed to a public GitHub repository. When I deployed Nextcloud, I felt excited because I was able to set up an enterprise-style cloud storage system in just a few minutes. Before this activity, I thought deploying a system like this would require a lot of complicated manual work. Seeing the application and database work together helped me understand how useful containerization can be in real-world situations.

Since Mission 1, my understanding of Cloud Computing has gradually improved. At first, I mainly understood it as accessing files, applications, and services through the internet. Now, I have a better idea of how cloud infrastructure can be configured, organized, and deployed using tools such as Docker and Docker Compose. I also realized that cloud engineering is not only about making a system work but also about making it reliable, manageable, and secure. As a fourth-year BSIT student, I know that I still have a lot to learn, especially when it comes to troubleshooting errors and understanding infrastructure configurations. However, this mission gave me more confidence to explore cloud technologies and helped me appreciate how the concepts we learn in our laboratory activities can be applied to actual IT projects.
