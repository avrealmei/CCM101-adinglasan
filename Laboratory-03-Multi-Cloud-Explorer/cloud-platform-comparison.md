## <a id="analysis-questions"></a>💡 Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services, having entered the market earliest and continuously expanded its portfolio with hundreds of specialized tools. This massive ecosystem allows developers to find purpose-built solutions for nearly any technical requirement imaginable. Consequently, it remains the most feature-rich cloud platform for complex enterprise architectures.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Microsoft technologies due to its native design alignment with Windows Server, Active Directory, and .NET applications. Organizations can effortlessly extend their on-premises Active Directory environments to the cloud using Microsoft Entra ID. Furthermore, cost-saving programs like the Azure Hybrid Benefit make it uniquely optimized for existing Microsoft license holders.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest provider in Artificial Intelligence and Kubernetes-driven workloads. As the birthplace of Kubernetes, GCP offers industry-leading container orchestration via Google Kubernetes Engine (GKE) and advanced machine learning infrastructure through Vertex AI. Additionally, its tight integration with powerful big data engines like BigQuery sets it apart for AI-driven data pipelines.

### 4. Which cloud platform would you personally choose and why?
I would personally choose Amazon Web Services (AWS) because of its unmatched market maturity, extensive documentation, and vast community support. Having a robust ecosystem with millions of certified professionals makes troubleshooting and finding stable integration patterns much more reliable. Its comprehensive range of infrastructure services provides the flexibility required to build scalable and fault-tolerant cloud systems.
