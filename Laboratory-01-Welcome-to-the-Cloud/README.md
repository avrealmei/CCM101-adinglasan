# 📖 Mission Overview

Welcome to **Laboratory Activity 1 – Welcome to the Cloud** for **CCM101 – Cloud Computing**.

In this laboratory activity, students were introduced to the Linux operating system using the Ubuntu 24.04 environment provided by KillerCoda. The activity simulated the onboarding process of a **Junior Cloud Infrastructure Engineer Trainee**, allowing students to experience the fundamental responsibilities of a cloud engineer.

The mission focused on creating and managing Linux user accounts, gathering system information, organizing files and directories, documenting technical work using Markdown, and building a professional Cloud Computing Portfolio using GitHub. These foundational skills will be applied throughout the semester in future laboratory activities involving cloud infrastructure, Linux administration, virtualization, Docker, Kubernetes, networking, monitoring, and DevOps.

---

# 🎯 Objectives

Upon completing this laboratory activity, I was able to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.

# 💻 Linux Commands Used

The following Linux CLI commands were used during this laboratory activity.

| Command | Purpose |
|---------|---------|
| `sudo useradd -m -s /bin/bash adinglasan` | Create a new Linux user with a Home directory and Bash shell |
| `sudo passwd adinglasan` | Set the password for the new user |
| `sudo usermod -aG sudo adinglasan` | Grant administrative (sudo) privileges |
| `su - adinglasan` | Switch to the new user account |
| `whoami` | Display the current username |
| `pwd` | Display the current working directory |
| `hostname` | Display the system hostname |
| `cat /etc/os-release \| grep PRETTY_NAME` | Display the Linux distribution |
| `uname -r` | Display the Linux kernel version |
| `lscpu \| grep "Model name"` | Display CPU information |
| `free -h` | Display total system memory |
| `df -h /` | Display available disk space |
| `nano system-information.md` | Create and edit the system information report |
| `cat system-information.md` | View the contents of the report |
| `mkdir Documents Notes Reports Screenshots` | Create the required workspace directories |
| `ls` | Display files and directories |
| `cd Notes` | Navigate to the Notes directory |
| `nano about-me.md` | Create the About Me document |
| `cat about-me.md` | Display the About Me document |
