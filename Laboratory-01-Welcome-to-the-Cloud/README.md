# 📖 Mission Overview

Congratulations! As part of this laboratory activity, I assumed the role of a **Junior Cloud Infrastructure Engineer Trainee** at **CloudNova Technologies**, a fictional company specializing in cloud infrastructure, virtualization, and enterprise cloud solutions.

This mission introduced the fundamentals of cloud computing by providing hands-on experience with the Linux operating system, cloud-based environments, and GitHub version control. Using the **KillerCoda Ubuntu Playground**, I completed onboarding tasks that simulated the daily responsibilities of a cloud engineer.

This laboratory also marked the beginning of my **Cloud Computing Portfolio**, which will serve as my professional workspace throughout the semester. All laboratory activities, technical documentation, projects, screenshots, and reflections will be organized within this repository using Git and GitHub.

---

# 🎯 Mission Objectives

Upon successfully completing this mission, I was able to:

- ☁️ Access a cloud-based Linux environment using KillerCoda.

# 💻 Linux Commands Used

| Command | Description |
|---------|-------------|
| `pwd` | Display the current working directory |
| `whoami` | Display the current username |
| `hostname` | Display the hostname |
| `ls` | List files and directories |
| `mkdir` | Create directories |
| `cd` | Change directories |
| `nano` | Create and edit Markdown files |
| `cat` | Display file contents |
| `uname -a` | Display Linux kernel information |
| `lscpu` | View CPU specifications |
| `free -h` | Display memory usage |
| `df -h` | Display available disk space |
| `git clone` | Clone a GitHub repository |
| `git status` | Check repository status |
| `git add .` | Stage project files |
| `git commit -m` | Commit changes |
| `git push origin main` | Upload commits to GitHub |
