## 📖 Description

Welcome to the first laboratory activity of **CCM101 – Cloud Computing**.

This laboratory introduces students to Linux, cloud environments, Git, GitHub, Markdown documentation, and version control through hands-on activities using KillerCoda.

Students complete onboarding tasks as a **Junior Cloud Infrastructure Engineer Trainee** while building a professional Cloud Computing Portfolio.
