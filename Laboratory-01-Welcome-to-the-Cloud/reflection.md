# 💭 Reflection

Completing **Laboratory Activity 1 – Welcome to the Cloud** provided me with my first hands-on experience in a cloud-based Linux environment. Through the KillerCoda Ubuntu Playground, I learned how to navigate the Linux operating system, use essential command-line interface (CLI) commands, organize files and directories, and document technical work using Markdown.

One of the most valuable lessons from this activity was understanding the importance of version control with Git and GitHub. Creating a professional Cloud Computing Portfolio showed me how cloud engineers document their work, manage project versions, and maintain organized repositories. These practices are essential for collaboration and software development in real-world IT environments.

This laboratory also improved my confidence in using Linux commands to gather system information, manage files, and work efficiently within the terminal. Although some commands and Git operations were new to me, completing each checkpoint helped strengthen my problem-solving skills and encouraged me to explore Linux further.

Overall, this activity served as an excellent introduction to cloud computing and Linux administration. It provided a strong foundation that will support future laboratory activities involving virtualization, networking, Docker, Kubernetes, cloud infrastructure, and DevOps technologies.

---

# 📘 Key Learnings

During this laboratory activity, I learned how to:

- ☁️ Access a cloud-based Linux environment using KillerCoda.
- 🐧 Navigate the Linux operating system using CLI commands.
- 📂 Create and organize directories and files efficiently.
- 📝 Write professional technical documentation using Markdown.
- 🐙 Use Git and GitHub for version control and repository management.
- 💻 Collect system information using Linux utilities.
- 🚀 Develop a professional Cloud Computing Portfolio.

# ⚙️ Challenges

While completing the laboratory activity, I encountered several challenges, including learning unfamiliar Linux commands, understanding Git workflows, and resolving authentication issues when pushing files to GitHub. By reviewing documentation, practicing commands, and troubleshooting errors step by step, I successfully completed each checkpoint and gained a better understanding of Linux and Git.

These challenges strengthened my patience, critical thinking, and troubleshooting abilities—skills that are essential for cloud engineers and IT professionals.
